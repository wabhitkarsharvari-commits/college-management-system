### 1. Clone the repository

```bash
git clone https://github.com/wabhitkarsharvari-commits/college-management-system.git
cd college-management-system
```

### 2. Start the frontend

Open a terminal in the project root and run:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.

### 3. Start the backend

Open a **second terminal** at the project root and run:

```bash
cd backend
npm install
```

Check `backend/package.json` for the available start script, and configure any required environment variables before starting the backend.
